Spring AI 架构图

分层架构 · Advisors 链 · 设计理念 — 《一个 Java 老手的 AI 第一线》专栏配套

ChatClient

  • Fluent API：prompt() → user() → call() → content()
  • 同步 call() / 流式 stream()——同一套 API 两种模式
  • Provider 无关：Ollama ↔ DeepSeek 切换不改代码
  • 和 WebClient 同源的设计哲学

ChatModel

  • 跨 Provider 的抽象接口层
  • 每个 Provider 对应一个实现类
  • 只做三件事：格式请求 → 发 HTTP → 解析响应
  • 通过 DI 注入给 ChatClient

Advisors 链

  • 责任链模式（前处理 + 后处理）
  • 内置 Memory · RAG · Safety 三件套
  • 可自定义，可通过 @Order 控制顺序
  • 本质就是 AI 领域的 Servlet Filter
